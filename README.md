# Portfel IKZE

1. Utwórz repozytorium na GitHubie (public), wgraj całą zawartość tego folderu (razem z ukrytym .github).
2. Settings -> Pages -> Deploy from branch -> main / root.
3. Actions -> "Aktualizacja cen" -> Run workflow (test). Dalej uruchamia się samo w dni robocze (17:20 UTC).
4. Otwórz https://TWOJ-LOGIN.github.io/NAZWA-REPO/ i kliknij Import -> wybierz moje-transakcje-IMPORT.json.

Transakcje są tylko w przeglądarce (localStorage). W repozytorium nie ma żadnych kwot. Rób "Kopia danych" od czasu do czasu.
Nowy ETF: dodaj blok do config.json (symbol Yahoo + kraje).
